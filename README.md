`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — an original one-liner inventing the most useless superpower an AI agent could have. The output is deterministic: every run produces byte-identical output.

> I can read minds, but only pigeons'. Every one of them is thinking about the same crumb, and none of them will share it.

## Run it

```sh
python3 main.py
```
